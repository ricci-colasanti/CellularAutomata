# Cellular Automata in JavaScript

A collection of cellular automata models written in JavaScript.

## Models Included

- **Conway's Game of Life** — classic 2D life simulation

## Getting Started

Each model runs in the browser with no dependencies.

1. Clone the repo:
   ```bash
   git clone https://git@github.com:ricci-colasanti/CellularAutomata.git
   ```
2. Open any `index.html` in the `models/` folder in your browser.
3. Or open page https://ricci-colasanti.github.io/CellularAutomata/
